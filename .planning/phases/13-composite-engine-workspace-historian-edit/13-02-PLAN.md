<planner_locks>
Planner decisions locked at plan level (research OQ2 deferred the scheme here — deciding now, property tests pin it):

- **Escaping scheme: per-segment percent-encoding.** Safe segment bytes = `[A-Za-z0-9._-]`; EVERY other byte (including `%` itself, spaces, control chars, non-ASCII, `/`-adjacent hazards) percent-encodes as `%XX`. Segments that ARE `.` or `..` (before escaping) are traversal-shaped → hard refusal, never escaped-around. NUL anywhere in a member path → hard refusal. This keeps ordinary names byte-identical on disk (diffable, nvim-friendly) while making hostile names safe and REVERSIBLE.
- **Case-collision policy: refuse.** After escaping, if two distinct member paths map to local paths equal under ASCII case-folding (APFS default), build_mapping refuses naming BOTH member paths. No unicode case-folding beyond ASCII (documented — NFC/NFD variants differ byte-wise and stay distinct files; the manifest records the exact mapping either way).
- **Mapping is recorded, never recomputed downstream:** build_mapping runs at checkout; the manifest (13-03) stores gateway↔local pairs. status/push read the manifest (Pitfall W1 anti-pattern: re-deriving).
- **No new exit slugs.** Mapping refusals ride CoreError::InvalidInput (exit 2) with the member path in the message. If implementation ever seems to need a new slug, STOP — new slugs are Three-Place ATOMIC events (Phase 8 contract) and that decision leaves this plan.
- proptest is a dev-dependency of ignition-core ONLY (`cargo add proptest --dev -p ignition-core`) — the lean agent build never compiles it.
</planner_locks>
