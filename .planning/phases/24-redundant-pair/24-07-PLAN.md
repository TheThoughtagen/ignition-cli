<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| target file → which node is written | After a failover the target's master is the standby |
| secret store → preflight output | Listings are names only; values must never be fetched |
| backup host account → read rights | Missing list rights would surface only after the master was written |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-24-24 | Tampering | writing to the now-standby node | high | mitigate | `master_active` by activity level in apply and rollback; tests for OnlyB, Both, Neither and rollback |
| T-24-25 | Information disclosure | secret preflight details | high | mitigate | Only `SecretNameListing` names are read; details list `provider/name` pairs; canary value seeded beside a name never appears (`preflight_secrets_missing_on_backup`) |
| T-24-26 | Denial of service | a deploy that cannot be verified on the backup | medium | mitigate | `backup_read` refuses before the lock when the backup account cannot read (D-02) |
| T-24-27 | Elevation of privilege | `skipped` read as `pass` | medium | mitigate | `Skipped` is its own status in `run.json` and tests assert it for REST-only, no-backup, rollback and no-reference cases |
</threat_model>
