  <name>Task 1: Real handlers — completions (provider/tag-path/named-query), TTL-stamped hover, cached diagnostics</name>
  <files>crates/ignition-cli/src/lsp.rs</files>
  <action>
    1. **Open-docs map**: `HashMap<Uri, (String /*text*/, u32 /*version*/)>` owned by the loop; `textDocument/didOpen` inserts, `didChange` (FULL sync) replaces text, `didClose` removes. This map is the diagnostics input — the server never fetches file contents elsewhere.
    2. **Completion** (`textDocument/completion`): merge three sources from `cache.snapshot()` — (a) provider names; (b) tag paths from `tag_trees` for the provider the document references (match by `[provider]` prefix in the path being completed; when none detected, include all providers' paths — keep it simple and honest); (c) named-query paths from `named_queries` for known projects. Trigger characters "/" and "." declared in 14-03 do the client-side pacing; the handler itself is a pure snapshot read → `Vec<CompletionItem>` (kind: Module for providers, File/Function for paths — lsp-types enums; labels are the raw paths). Empty snapshot (healthy:false) → empty list, never an error.
    3. **Hover** (`textDocument/hover`): word at position → look up in providers / tag paths / named-query paths → `Hover` with contents containing the match description AND the snapshot age, e.g. `"[default]Motor — gateway snapshot 12s old (TTL 30s)"` (Pitfall 4: staleness is stamped into the payload). No match → `Ok(None)`.
    4. **Diagnostics** (`publishDiagnostics` from cache): for each open doc, compute diagnostics from the CURRENT snapshot: unknown provider reference (warn), tag path absent from the cached tree (hint-grade warning, include the age stamp), named-query path not in cached list. Publish after didOpen/didChange, AND after each refresh cycle — the loop consumes the refresher's version channel from 14-03 via `crossbeam_channel::select!` over `connection.receiver` + version channel (the loop's only structural change; handlers stay pure). On `didClose`/publish-empty, clear diagnostics for the URI.
    5. **didSave → refresh kick**: send on the kick channel (14-03's `kick_rx`) — best-effort, never awaited by the request path.
    6. Unit tests: handler functions over a hand-built fake Snapshot (pure fns taking `&Snapshot` + text + position) — completion merge coverage (all three families), hover age-stamp presence, diagnostic computation for all three failure classes. Anti-sabotage: remove one source from the merge → test red → restore.
  </action>
  <verify>`cargo test -p ignition-cli lsp` green (handler unit tests); `cargo build -p ignition-cli` clean; `cargo clippy --workspace --all-targets -- -D warnings` clean; the loop select compiles against lsp-server 0.10's crossbeam receiver (verifies the 14-03 channel handoff).</verify>
  <done>All three completion families served from cache; hover stamps staleness; diagnostics publish from cache on edits and refreshes; handlers remain zero-network by construction (only fns over &Snapshot + doc text).</done>
