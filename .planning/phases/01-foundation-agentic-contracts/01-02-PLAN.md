| exit | variant class | slug examples |
|-----|---------------|---------------|
| 1 | Internal (catch-all, "report as bug") | `internal` |
| 2 | ConfirmationRequired (destructive without --yes; clap renders its own usage errors — never hook clap) | `confirmation_required` |
| 3 | ProfileNotFound, NoActiveProfile, SecretUnavailable, ConfigInvalid (unreadable TOML / bad shape) | `profile_not_found`, `no_active_profile`, `secret_unavailable`, `config_invalid` |
| 4 | Network { url, source: reqwest::Error } (unreachable/timeout/TLS) | `network_error` |
| 5 | Auth { status } (gateway 401/403) | `auth_rejected` |
| 6 | GatewayTooOld { found, minimum } (also future: project-not-found-on-gateway, rig-not-running) | `gateway_too_old` |
| 7 | Rig (reserved — first used Phase 4) | `rig_error` |

Every variant carries: `code() -> &'static str` (stable slug — public contract, never respell), `exit_code() -> u8`, `hint() -> Option<String>`. ErrorBody carries `endpoint: Option<String>` (URL/path when a request was involved) — populate it for network/auth/target-state variants.

Also in error.rs: `ErrorEnvelope<'a> { ok: false-const, profile: Option<&'a str>, error: ErrorBody }` + `ErrorBody { code, message, endpoint, hint }` (serde Serialize, field order matters for goldens: ok, profile, error / code, message, endpoint, hint).
