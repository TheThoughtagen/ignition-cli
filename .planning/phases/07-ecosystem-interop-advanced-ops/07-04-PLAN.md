<objective>
The interop trio (INTR-01/02/03) — round-trip script editing, external linter delegation, offline tag-export browsing.

Purpose: the CLI becomes a citizen of the WhiskeyHouse editing ecosystem: nvim/VS Code edit decoded `.py` sidecars, ignition-lint gates quality, git-module exports browse without a gateway.
Output: `scripts_codec` pure module + export/import flags, `ign lint` delegation, `tags browse --from-export`, one additive slug, TUI row for lint, README.

Planner decisions (research Open Questions resolved):
- **lint exit semantics = doctor posture default** (exit 0 whenever the child RAN; findings + `child_exit_code` + parsed JSON report in data) with `--strict` literal passthrough for CI — the documented exception shape. Never let findings masquerade as CoreError::Internal (Pitfall 6).
- **Sidecar addressing = counter-named sidecars + JSON-pointer manifest**: `<member>.<n>.py` siblings + `scripts-manifest.json` mapping JSON-pointer addresses → {sidecar, indent_prefix}. Marker-free exported JSON (gateway-clean; research anti-pattern).
- **Round-trip strategy = span-level splicing**: parse with serde_json `preserve_order` (feature flag on serde_json — the one workspace-feature change; verify it is already enabled, if not enable it — it is a feature of an EXISTING dep, not a new dep) for addressing, but splice replacement strings at the raw span where the value lives; acceptance = byte-equality of UNEDITED re-encoded members (Pitfall 4).
- **Decode heuristic**: only values under SCRIPT_KEYS (`script, code, eventScript, transform, onActionPerformed, onChange, onStartup, onShutdown, expression`) that look like scripts (contain `\n` post-decode-probe / multi-line) decode to sidecars; expressions pass through (Pitfall 5). script-python `.py` members never decode (already plain — README states the scope).
- **from-export is offline**: no gateway, no credential → envelope `profile: null` + data `source: "export"` + `origin` (the rig-verb precedent for non-gateway commands). `--filter` still applies client-side. NO new TUI row (a flag on the existing `tags browse` leaf — the clap walk only sees leaves).
</objective>
