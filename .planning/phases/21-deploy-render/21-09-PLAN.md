1. `tree.rs`: `pub const RENDER_MARKER: &str = "render.json"`; `RenderMarker { schema_version: u32, gateway: String, env: String, mode: String, render_sha256: String, files: Vec<MarkerFile> }` and `MarkerFile { path: String, sha256: String, bytes: u64 }` (Serialize, Deserialize, deny_unknown_fields; files byte-sorted; serialized with `serde_json::to_string_pretty` plus one LF; this is ign's own file, not a gateway file, and is never part of the digest). `write_out(tree, out, marker) -> Result<(), CoreError>` in two phases.
   Check phase (no writes): `std::fs::symlink_metadata(out)`; absent → plan a fresh write; a symlink, or anything that is not a directory → refuse; a directory → walk it recursively with `symlink_metadata` (any symlink or special entry → refuse naming it); no entries → fresh; otherwise require a regular `render.json` that parses as `RenderMarker` with `schema_version` 1 and the same `gateway` and `env`, every regular file other than the marker listed in it with an equal sha256, every listed file present, no directory that holds no listed file, and every listed path present in the new tree; any miss → refuse naming the reason and first offending path, suggesting to remove the directory or choose an empty one.
   Write phase: fresh → create missing ancestors, then create the leaf with `std::fs::create_dir` (an AlreadyExists here means another writer won: refuse). For each file in byte order: create parent directories inside `out`; a new path is opened with `OpenOptions::new().write(true).create_new(true)`; a path listed in the prior marker is replaced by writing `<name>.ign-render-tmp` with `create_new` and renaming over it. Finally write `render.json.ign-render-tmp` with `create_new` and rename it to `render.json`. Never call any remove function. Ladder refusals are `CoreError::InvalidInput` (exit 2); I/O failures map the way `actions/workspace.rs` maps local write failures.
