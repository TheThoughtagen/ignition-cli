<objective>
Guard the release order and the git-module handover: `--release` is a semver tag, an older release than the gateway last received from `ign` refuses without `--allow-downgrade`, and the first `ign` deploy of a project must match what the gateway already runs unless `--allow-first-change` gives a reason; an unchanged first deploy plans a record-only adoption.

Purpose: D-02, D-03, D-12, K13, K14 and the record read side of V5, all visible in `--check` (V10) so a CI check job fails before an approval is requested.
Output: `Release`, `ReleaseOrder`, `ReleaseRecord` (strict parse, `to_bytes`), `ProjectAction::Record`, the two gates, the two flags, reserved mode `projects`, result keys, README.
</objective>
