<objective>
Make the `.git` refusal and the release-record read work on the hosts production runs on: Linux and Windows nodes reached over ssh, with the Windows Hidden-attribute trap closed, and prove both on the capture hosts after the 25-03 grant.

Purpose: DPRJ-04 on the real fleet (WIGNVM hosts are Windows) and the record read D-03, D-06 and D-12 depend on. Research F3, A4, Pitfall 4.
Output: the sftp `ProjectHost` for POSIX and Windows, `winps::GIT_ENTRY`, the `Ssh` arm of `project_host_for_node`, an ignored live test, `## C-H after grant (25-08)`, README account-scope rows.

Estimate note (revision 2026-10-22): the raw estimate is 120k against the 100k smart zone, and the plan is kept whole on purpose. Linux and Windows share one `ProjectHost` trait, one sftp `project_ops.rs`, one live test file and one `## C-H after grant (25-08)` capture session against the same two hosts after the 25-03 grant. Splitting Windows off would ship an `Ssh` arm that either refuses Windows nodes (every production WIGNVM host) or probes them without the Hidden-attribute fix, which is the A4/Pitfall 4 failure (the `.git` refusal silently off on Windows prod), and would need a second live session. Most of the cost is live host round trips, not reading code.
</objective>
