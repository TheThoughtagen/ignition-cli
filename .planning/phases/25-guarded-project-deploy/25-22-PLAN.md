<objective>
Close G-25-7: the released Windows ign.exe must start on a clean Windows Server that has no VC++ redistributable.

Today release.yml builds x86_64-pc-windows-msvc with the dynamic CRT, so ign.exe imports vcruntime140.dll and exits 0xC0000135 (STATUS_DLL_NOT_FOUND) on ign-win-836 until the redistributable is installed. This is the binary the deploy-projects check and apply jobs download and run on a Windows runner (UAT test 3).

This plan links the C runtime statically on the Windows release target only. It adds a release-time check that fails, before anything is packaged or uploaded, when ign.exe imports a vcruntime or msvcp DLL. It also corrects the two documents that describe the release assets.

Purpose: the deploy workflow's Windows path (the verified upload of DPRJ-01 and the `--check` of DPRJ-05) must run on a stock Windows Server runner without hand-installed prerequisites.
Output: the updated release.yml, an offline release harness script, and corrected RELEASING.md and docs/installation.md.
</objective>
