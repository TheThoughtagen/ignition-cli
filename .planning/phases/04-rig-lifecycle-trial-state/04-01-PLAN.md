- `compose_version(runner) -> Result<semver-ish, CoreError>`: run `["version"]`, parse `Docker Compose version v5.1.2` → require major ≥ 2; absence/failure → `CoreError::Rig` with install hint (v1 `docker-compose` binary never answers to `docker compose`).

**`rig_up(runner, plan, wait_timeout_s, gateway: Option<&dyn GatewayApi>) -> RigUpResult`**:
1. `compose_version` check (fail fast, exit 7 with hint)
2. `port_preflight` → any cross-project conflict → `CoreError::Rig` message `"port <p> in use by <container> (rig <other>)"`
3. `up_args` run (default wait-timeout 300s — research Pitfall 3: healthcheck-blocking + image pull headroom); nonzero → Rig with stderr tail
4. commissioned-wait via `poll.rs` VERBATIM (research Pattern 4): probe = header-less `status_ping()` on the FIRST http-publishing service's port (or the gateway URL derived from plan; poll deadline = wait_timeout). Probe translation: `RUNNING` → Done; `STARTING`/transport-refused/503 → Pending; 3xx/classify→`GatewayNotCommissioned` → **probe catches it and returns Pending("gateway uncommissioned — open http://<host>:<port>/welcome")** — never aborts (poll.rs retry set is LOCKED, unchanged). Auth can't fire (header-less).
5. Deadline expiry with terminal uncommissioned → SUCCESS as data (research Pattern 4: fresh-volume rigs report `"up, uncommissioned"` — exit 0 + warning inside `data`, the version-command degradation precedent; headless commissioning does NOT exist — out of scope). Deadline expiry still STARTING → Rig error.
6. `RigUpResult` serde shape (all keys always): `{rig, project, state: "running"|"uncommissioned", gateway_url, warnings: [...]}`.

**`rig_down(runner, plan)`**: version check → `down_args(volumes=false)` → `RigDownResult {rig, project, state: "down"}`. NOT guarded in this plan (plain down = stop; `-v` volume deletion arrives with reset in 04-02).

**`rig_status(runner, plan) -> RigStatusResult`**: version check → `ps_args` → parse → allowlist serialization (research anti-pattern: NEVER dump compose config/inspect — it contains `GATEWAY_ADMIN_PASSWORD` etc.): `{rig, project, compose_file, services: [{name, state, health, exit_code, publishers: [{published_port, target_port, protocol}]}], volumes: [<names via volume_ls>], ports_free: bool}`. All family keys always present (empty vecs when none). Exit 0 even when services are down — state is data.

Gateway URL derivation helper `pub(crate) fn gateway_url_from(plan) -> Option<String>`: first publisher with target port 8088/443 → `http(s)://localhost:<published>`. Keep it a documented heuristic (data carries what it derived from).
