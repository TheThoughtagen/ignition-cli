## Premise check

Verified in `plan.rs` before changing anything. `delete_set` only keeps paths present in `observed.mode`, and `deleted_here` groups them with `mode_layer`. So a `removed` entry always has a mode copy, `effective` is that mode copy, and `PlanEntry.files` are exactly its files with `live_sha256: Some`. `PlanFile.path` and `RelPath::as_str` are both the collection path, so a byte-exact comparison is valid. The premise holds.
