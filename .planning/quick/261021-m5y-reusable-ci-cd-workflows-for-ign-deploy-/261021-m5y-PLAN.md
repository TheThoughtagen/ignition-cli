Locked user decisions, all honoured as given:
- (L1) Reusable `workflow_call` workflows live in ignition-cli. Callers pin the ign version.
- (L2) The workflows are runner-agnostic: `runs-on` is a JSON label-list input defaulting to `["self-hosted"]`, the release asset is chosen per `runner.os`, and every step uses `shell: bash`.
- (L3) The apply uses `--designers wait --designers-timeout <input, default 600>`. A timeout fails before any write and notifies `github.actor` (PR comment, else commit comment, plus the job summary).
- (L4) The .gwbk is always taken.

No release tag is pushed. No worktree is created.

Choices made at Claude's discretion (recorded here so the reviewer sees them):
- **No composite action.** A `uses: ./.github/actions/...` inside a called workflow resolves against the CALLER's checkout. A cross-repo reference needs a ref the workflow cannot know about itself. So the install, config and env-preamble steps are duplicated in both files, wrapped in `shared:` marker regions, and a harness check keeps them byte-identical.
- **Profiles come from plain inputs.** Profile names and gateway URLs are `master-profile`/`master-url`/`backup-profile`/`backup-url` inputs. Only tokens and the ssh key are secrets (`IGN_MASTER_TOKEN`, `IGN_BACKUP_TOKEN`, `IGN_SSH_KEY`). A URL is not a credential: ign prints it in every error envelope's `endpoint`. Fixed secret names also let `secrets: inherit` carry environment-scoped secrets.
- **Notification scope.** Every failed apply notifies, not only a designers timeout. The comment @mentions `github.actor`, and also `github.triggering_actor` when it differs (a re-run).
- **destructive_change_refused.** Exit 2 with `destructive_change_refused` is reported as a destructive-plan refusal, not as a pipeline bug, because it is a policy refusal. The workflow never passes the destructive or drift allow flags.
- **Linux ARM64.** The install also maps Linux ARM64 to the published aarch64 asset.

**Workflow skeleton.** Create .github/workflows/deploy-plan.yml as a reusable workflow (`on: workflow_call`, per L1).

Inputs:
- `env` (string, required).
- `ign-version` (string, required; a release tag such as v1.6.0-rc1).
- `runs-on` (string, default the JSON text `["self-hosted"]`, used as `runs-on: ${{ fromJSON(inputs.runs-on) }}`, per L2).
- `repo-dir` (string, default `.`).
- `master-profile`, `master-url`, `backup-profile`, `backup-url` (strings, default empty).
- `ssl-verify` (boolean, default true).
- `ssh-key-env` (string, default empty; the env var NAME that the target's `nodes.*.ssh.key_env` names).

Secret: `IGN_SSH_KEY`, not required. Plan opens no gateway session, so it takes no token secrets.

Workflow output: `plan_sha256`, from `jobs.plan.outputs.plan_sha256`.

One job, `plan`:
- No `environment:`.
- `permissions` of `contents: read` and `pull-requests: write`.
- Job output `plan_sha256` from `steps.report.outputs.plan_sha256`.

**Step a: checkout.** `actions/checkout@v7` with `persist-credentials: false`. ign only reads the tree, and this keeps the token out of .git/config on a shared runner.

**Step b: "Install ign"** (`shell: bash`).
- Step env: `IGN_VERSION` from `inputs.ign-version`, and the constant `IGN_RELEASE_BASE`, set to the GitHub releases download base of TheThoughtagen/ignition-cli.
- The whole body sits inside a `# >>> body:install-ign` / `# <<< body:install-ign` region, and inside that a `# >>> shared:install-ign` / `# <<< shared:install-ign` region.
- Behaviour, in order:
  1. `set -euo pipefail`.
  2. Refuse an `IGN_VERSION` that does not match `^v[0-9]+(\.[0-9]+){1,2}(-[0-9A-Za-z.]+)?$`, before any network call.
  3. Map `RUNNER_OS`/`RUNNER_ARCH` to a target: Linux+X64 is x86_64-unknown-linux-gnu (tar.gz, binary `ign`); Linux+ARM64 is aarch64-unknown-linux-gnu; Windows+X64 is x86_64-pc-windows-msvc (zip, binary `ign.exe`). Anything else gets a `::error::` naming the OS and arch, then exit 1.
  4. Compute a temp root: `RUNNER_TEMP`, converted with `cygpath -u` on Windows. Recreate `<root>/ign-install` empty.
  5. Download the asset and its `.sha256` with curl, flags `-fsSL --proto =https --tlsv1.2 --retry 3`.
  6. Parse the `.sha256`. The first field must be 64 lowercase hex. The second field, with CR and a leading `*` stripped, must equal the asset name. Compare the first field with the `sha256sum` of the download. On any mismatch, print `::error::` naming the asset and both hashes and exit 1, BEFORE extraction.
  7. Extract into a fresh `x/` subdirectory: `tar -xzf` for tarballs. For a zip, use `unzip -q` when unzip is on PATH; otherwise use `powershell.exe -NoProfile -NonInteractive -Command Expand-Archive` with `cygpath -w` paths.
  8. Require `x/ign-<tag>-<target>/<binary>` to be a regular file and not a symlink. `chmod +x` it off Windows.
  9. Run it with `--version` and print the result.
  10. Append `IGN_BIN=<that path>` to `GITHUB_ENV`. Never resolve `ign` from PATH: a self-hosted runner may have another ign installed.

**Step c: "Write ign config"** (`shell: bash`).
- Step env from the four profile inputs and `ssl-verify`.
- Body region `body:write-config`, containing `shared:write-config`.
- Behaviour:
  1. Validate profile names against `^[A-Za-z0-9][A-Za-z0-9._-]{0,63}$`.
  2. Validate URLs: they must start with `http://` or `https://` and contain no whitespace, quote, backslash or control character.
  3. A profile and its URL must be given together. The backup name must differ from the master name. `ssl-verify` must be exactly `true` or `false`.
  4. Recreate `<root>/ign-config/` and write `config.toml` there, with one quoted-key `[profiles."<name>"]` table per given profile. Each table holds only `url` and `ssl_verify`: no `auth` key, and never a token. README credential-order step 1 (`IGNITION_TOKEN_<PROFILE_UP>`) answers every auth shape. With no profiles, write an empty file.
  5. Append `IGNITION_CLI_CONFIG=<path>` to `GITHUB_ENV`, in `cygpath -w` form on Windows because ign.exe reads it natively. This isolates ign from the runner user's own config.toml.
  6. Echo only the profile names.

**Step d: "Run ign deploy plan"** (`shell: bash`, `id: run`).
- Step env: `IGN_ENV`, `IGN_REPO_DIR`, `IGN_SSH_KEY_ENV`, `IGN_MASTER_PROFILE` and `IGN_BACKUP_PROFILE` from inputs; `IGN_SSH_KEY` from `secrets.IGN_SSH_KEY`.
- Body region `body:run-plan`. It starts with a `shared:ign-env` region (Task 2 reuses it byte for byte), then the plan tail.
- The `shared:ign-env` region:
  1. `set -uo pipefail`.
  2. Unset any ambient IGNITION_TOKEN, IGNITION_USER, IGNITION_PASSWORD, IGNITION_PROFILE, IGNITION_YES and IGNITION_JSON.
  3. On Windows only, prepend `<SYSTEMROOT as a POSIX path>/System32/OpenSSH` to PATH. Fact 10: ign starts ssh by bare name, and Git Bash otherwise hands it MSYS ssh. Then, if `ssh -V` does not report OpenSSH_for_Windows: fail when `IGN_SSH_KEY_ENV` is set (an ssh target), otherwise print a `::warning::`.
  4. For each pair (IGN_MASTER_PROFILE, IGN_MASTER_TOKEN) and (IGN_BACKUP_PROFILE, IGN_BACKUP_TOKEN):
     - A token without its profile is an error.
     - When both are present, export `IGNITION_TOKEN_` + the profile name uppercased with every non-alphanumeric character turned into `_`, set to the token.
     - A token variable that is unset counts as absent; plan never sets one.
  5. `IGN_SSH_KEY` without `IGN_SSH_KEY_ENV` is an error.
  6. When `IGN_SSH_KEY_ENV` is set:
     - It must match `^[A-Za-z_][A-Za-z0-9_]*$`.
     - It must not be PATH, HOME, BASH_ENV, ENV, IFS, SHELLOPTS, PS4 or CDPATH, and must not begin with GITHUB_, RUNNER_, ACTIONS_, IGNITION_, LD_ or DYLD_.
     - `IGN_SSH_KEY` must be non-empty.
     - Export the key under that name.
  7. Unset IGN_MASTER_TOKEN, IGN_BACKUP_TOKEN and IGN_SSH_KEY.
  8. Recreate `<root>/ign-out`.
- The plan tail:
  - With `set +e`, run `"$IGN_BIN" deploy plan --env "$IGN_ENV" --repo "$IGN_REPO_DIR" --json`. Send stdout to `ign-out/plan.stdout.json` and stderr to `ign-out/plan.stderr.json`.
  - Write `exit_code=<rc>` to `GITHUB_OUTPUT` and exit 0. The report step decides pass or fail.
  - No `--diff`, so entries carry paths and hashes only.

**Step e: "Report plan"** (`actions/github-script@v9`, `id: report`, `if: always()`).
- Step env: `IGN_ENV`, `IGN_EXIT` from `steps.run.outputs.exit_code`, and `IGN_VERSION`.
