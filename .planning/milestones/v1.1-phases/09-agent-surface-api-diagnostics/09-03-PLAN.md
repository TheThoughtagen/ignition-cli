1. New `crates/ignition-core/src/client/apicall.rs` (declare in client/mod.rs alongside the other capability modules):
   - `pub struct ApiCallRequest { pub method: String, pub path: String, pub body: Option<String>, pub headers: Vec<(String, String)>, pub query: Vec<(String, String)> }` — body is raw text passthrough (JSON or otherwise; the gateway's answer classifies).
   - `pub struct ApiCallData { pub status: u16, pub data: Box<serde_json::value::RawValue> }` — **verbatim decision (research OQ1, RawValue)**: the success path captures the response TEXT and embeds it via `serde_json::value::RawValue::from_string(text)` (which both preserves bytes/order AND validates JSON — one call, no parse-re-serialize). Decision pinned: "gateway-verbatim" = no field dropped, no value coerced, key order preserved.
   - `pub fn refuse_auth_headers(headers: &[(String, String)]) -> Result<(), CoreError>` per research Pattern 2: `REFUSED_AUTH_HEADERS: [&str; 3] = ["authorization", "x-ignition-api-token", "cookie"]`, compare `name.trim().to_ascii_lowercase()` (Pitfall 3: HTTP header names are case-insensitive; trim beats whitespace-prefix smuggling), refuse with `CoreError::InvalidInput` naming the header + the profile-auth rule.
   - `pub fn validate_path(path: &str) -> Result<(), CoreError>`: (a) must start with `'/'` else InvalidInput naming the rule; (b) refuse `url::Url::parse(path)` succeeding with a host (absolute/foreign URLs — `url_for`'s join would silently rebase); (c) refuse `'?'` in path with a hint naming `--query` (ONE query mechanism — research OQ4/Pitfall 4).
   - `pub async fn api_call(&self, call: &ApiCallRequest) -> Result<ApiCallData, CoreError>` on the `GatewayApi` trait + `ReqwestGatewayApi` impl (client/mod.rs): `url_for(&call.path)` → `reqwest::Method::from_bytes(method.to_uppercase().as_bytes())` (unsupported verb → InvalidInput) → user headers via a `.header(name, value)` loop (the `webdev_route_call` extra_headers precedent, client/mod.rs:643-648) → `.query(&pairs)` when query non-empty → optional `.body(text)` ANY method (GET/DELETE body passthrough allowed — curl parity, decision 6) → `self.apply_auth(request)` (ONE auth site — redaction boundary) → `self.send_and_classify_for_api(...)` (09-01's) → success: `response.text()` → `RawValue::from_string`. Non-JSON 2xx body (RawValue::from_string errors): `CoreError::Internal` with an explanatory message ("gateway answered 2xx with a non-JSON body — api call returns JSON; use logs/backup downloads for binary endpoints") — honest unmodeled-shape class, documented in README (Task 3).
