- **No-op decision = content, never exit code:** after Editor.open, re-encode the tree and byte-compare against the ORIGINAL export zip's re-encode. Identical → clean no-op exit (no push, no prompt, no guard) — well-defined BECAUSE the codec's unedited round-trip is byte-exact (13-03 proved it at tree scale).
- **Staleness is NOT --yes-able:** drift between the fetch-time member_hashes snapshot and a fresh pre-push export on the TARGET member refuses with InvalidInput "resource changed on gateway since fetch — re-run to fetch fresh". No flag overrides it in this phase (Pitfall E2; forcing it would clobber a concurrent Designer edit).
- **Temp discipline:** one `tempfile::TempDir` per invocation (unique), permissions 0700, Drop-guard removal; a fail-closed encode KEEPS the tree and the error message prints its path (recovery path).
- **Editor resolution order:** `VISUAL` → `EDITOR` → platform fallback (macOS: `open -t -W` is NOT acceptable — W-flag semantics vary; instead refuse with a clear "set $EDITOR" message; document in 13-08's README section). The editor arg vector is `<editor> <target-path>` plus nothing else; IDE-style editors needing `--wait` flags go in `EDITOR` itself (`EDITOR="code --wait"`) — README documents this (13-08).
- **No new exit slugs; no route changes;** the whole-tree codec path means push rides the existing project_import — the `<resource-path>` argument scopes which file the EDITOR opens, never a new push path (research: deferred).
