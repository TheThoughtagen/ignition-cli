## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| two profiles → two gateways | The peer profile resolves its own credentials |
| gateway status → operator decision | A wrong "active" answer could lead an operator to write to the standby |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-24-12 | Spoofing | active-node decision | high | mitigate | `active_node` reads `activityLevel` only (Phase 20 tests); `both` is printed as split-brain, never resolved to one side; tests for all four outcomes |
| T-24-13 | Information disclosure | peer credentials | medium | mitigate | Peer resolved through `Session::resolve_side` (its own secret chain, never printed); the envelope names the profile only |
| T-24-14 | Denial of service | `--peer` loops on the same gateway | low | mitigate | Same-profile `--peer` refused before any request |
