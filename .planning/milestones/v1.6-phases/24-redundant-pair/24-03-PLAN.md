## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| rendered tree → request path | Provider names come from user-authored JSON and become a URL segment |
| gateway → secret listing | A listing could in principle carry more than names |
| runner → master resync | The only new write; a retry or a wrong session would be a silent second action |
