<objective>
Add the carried-forward pre-checks to project deploys: no import while a Designer session is open (unless explicitly allowed and recorded), and no write to a gateway that is not the one the target names, sharing one implementation with `deploy apply`.

Purpose: CONTEXT "Carried forward": Designer/session pre-check before import (23 D-14/D-15 vocabulary), research Pitfall 9 (the finding function is coupled to `PreflightInput`), and the wrong-gateway spoofing threat from the research security domain.
Output: `designers_gate` and the shared wrong-target comparison in `preflight.rs`, the project preflights, `--designers`/`--designers-timeout` on `deploy projects`, tests, README.
</objective>
