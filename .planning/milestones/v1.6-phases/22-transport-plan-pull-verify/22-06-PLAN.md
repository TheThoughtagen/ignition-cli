## Trust Boundaries

| Boundary | Description |

| remote sftp-server → listings and downloads | The host controls names, sizes, listing text and error text |
| runner temp dir → hashes | Downloaded bytes are hashed locally |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-22-24 | Tampering | silent partial read (error hidden by `-` prefix) | high | mitigate | No `-` prefix; existence-first sessions; any exit or stderr is `transport_failed`; downloaded dirs checked against listings |
| T-22-25 | Tampering | hostile names injected into later batches | high | mitigate | Remote names never interpolated; only validated segments, providers and fixed paths enter batch lines |
| T-22-26 | Tampering | hostile names in a recursive download (`..`, `/`) | medium | mitigate | The sftp client refuses such names; local `walk_out` refuses symlinks, special files and non-UTF-8 names; listing parser refuses `.`, `..`, `/` |
| T-22-27 | Denial of service | huge remote files fill the runner disk | low | accept | Caps are enforced after download; the host is the deploy target the operator controls; disk fill needs host write access |
| T-22-28 | Tampering | remote symlink inside a resource dir is skipped by `get -R` | low | accept | Verified behaviour pinned by `sftp_get_skips_symlinks_documented`; gateways do not write symlinks under `config/resources`; Windows reparse-point behaviour is a C7a capture item (22-12) |
| T-22-29 | Information disclosure | downloaded config left on the runner | medium | mitigate | Per-read `TempDir` deleted on drop |
</threat_model>
