<objective>
Implement the on-box batch for Linux ssh nodes: a POSIX `sh` script uploaded with the staged files and run in one ssh call under the lock, proven against the same conformance table as the local host.

Purpose: D-01 replaces per-file sftp renames inside the lock with one remote call. Linux is the simpler of the two script hosts (no CLIXML, no OEM code page) and runs on every unix CI leg, so it fixes the script contract (stub, work list, index-based results) before the PowerShell port in 23-08 and 23-20.
Output: `scripts/commit.sh`, `RemoteShell::exec_posix` and its local seam, `impl ApplyHost for SftpTransport` (Linux), the Linux `TreeMirror::commit` on the script, conformance rows for the sh host.
</objective>
